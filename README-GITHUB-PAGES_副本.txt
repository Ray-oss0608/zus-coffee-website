ZUS Coffee Assignment 3 - GitHub Pages Publishing

This project is prepared for GitHub Pages.

IMPORTANT:
1. Upload the CONTENTS of this folder to the ROOT of a PUBLIC GitHub repository.
2. Keep index.html at the repository root (do not put it inside another folder).
3. Keep the css, images, video, and design-plan folders in their current locations.
4. In GitHub, open Settings > Pages.
5. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
6. Click Save and wait for deployment to finish.
7. Copy both the repository URL and the published website URL for submission.

The contact form in this student project is a visual demonstration and does not send messages.
